## Критический путь (для дорожной карты)

Ключевая последовательность для кейса ставок:

```
A1 (модуль ставок в АБС)
   └─► T1 (API интеграции на стороне АБС) + A4 (callback)
          └─► T4 (получение ставок в Deposit Service, кэш)
                 ├─► D4 ─► T5 (ставки в системе кол-центра банка)        [UC-2]
                 └─► T2 (SFTP-выгрузка) ─► T6 (приём у партнёра)          [UC-3]

T3 (SFTP-сервер) — параллельно, нужен к моменту T2
```

Без `A1` (ведение ставок в АБС) не запускается ни один канал раздачи ставок — это первый шаг.
