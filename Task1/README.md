# Task 1. Карта IT-ландшафта и схема интеграции приложений

Артефакты подготовлены в формате draw.io:

- `it-landscape-current.drawio` — карта текущего IT-ландшафта в формате матрицы:
  строки — подразделения организационной структуры,
  колонки — бизнес-возможности второго уровня (Business Capability Map).

- `application-integration-current.drawio` — текущая схема интеграции приложений
  с указанием категорий пользователей, IT-систем и бизнес-сущностей на информационных потоках.

Ключевые ограничения, отражённые на схемах:

- расчёт ставок по депозитам выполняется вручную в Excel (бэк-офис кредитов);
- обмен данными между бэк-офисом депозитов и кредитов — через email;
- интернет-банк интегрирован с АБС напрямую через Oracle БД (без API/сервисного слоя);
- сайт используется только как маркетинговый канал;
- АБС — центральная система учёта операций и договоров.
